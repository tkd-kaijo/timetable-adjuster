# 時間割調整アプリ

時間割CSVを読み込み、授業コマの譲渡・交換・移動案を作成するブラウザアプリです。

## 使い方

1. GitHub Pagesの公開ページを開きます。
2. 「ファイルを選ぶ」から時間割CSVを読み込みます。
3. 調整メニューを選び、条件を指定して調整案を検索します。
4. 必要に応じて完成形CSV、先生・クラス時間割PDF、教務部提出用ファイルを出力します。

CSVの読み込みと処理はブラウザ内で行われ、サーバーには送信されません。

## ホーム画面への追加

iPhone / iPadではSafariの共有メニューから「ホーム画面に追加」を選ぶと、専用アイコンのアプリとして利用できます。
